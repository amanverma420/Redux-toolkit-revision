# Redux Toolkit

A small React application demonstrating state management with Redux Toolkit and React Redux. The app includes a counter with increment, decrement, reset, and increment-by-amount actions.

## Project location

The application is in the [`react-redux`](./react-redux/) folder.

## Getting started

From the project folder, install dependencies and start the Vite development server:

```bash
cd react-redux
npm install
npm run dev
```

## Available scripts

Run these commands from `react-redux`:

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the app for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Check the code with ESLint |

## Tech stack

- React
- Redux Toolkit
- React Redux
- Vite
